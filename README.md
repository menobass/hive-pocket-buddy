# Hive Home Widget

question for you. Can you build a crypto portolio widget? something that you can put on a home screen, on a phone. It would be for hive tokens (cryptocurreny hive.io) you would enter the accounts/wallets you'd want to track, it would then give you VP/RC and Balances per account, and it would give you a global total of Hive Power, Hive Tokens and HBD for all the accounts you are tracking.
